# Personal Finance Management System

This is my project for the A-Level Computer Science subject. I developed it on my own during the last year of high school.

It is a simple desktop application for tracking personal expenses. It helps sort expenses by categories and accounts, and it supports multiple users.

To keep the implementation simple, I used an SQLite database stored as a single file in the project folder.

## Tech stack

- Java
- JavaFX
- Maven
- SQLite
